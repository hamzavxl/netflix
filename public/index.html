HOW TO USE

iPhone / iOS
  1. [Safari ONLY] You must access our website using Safari browser.
  2. Enter your CDK code and click Verify.
  3. Choose Phone / Tablet.
  4. Click "Open Login Link" or copy and paste it into Safari.
  5. The Netflix app will open and log in automatically.
Android Phone
  1. Update both the Netflix app and Chrome browser to the latest version on your phone.
  2. Enter your CDK code and click Verify.
  3. Choose Phone / Tablet.
  4. Click Open Netflix or copy the link to Chrome browser.
  5. Click "Open App" if prompted to log in automatically.
PC & Smart TV
  1. PC: Copy the link and open it in Chrome/Safari to log in automatically.
  2. Smart TV: Open Netflix on TV -> Sign In -> Get code.
  3. Select "Smart TV" on our website, enter the TV screen code, and click Activate.
System API Documentation

Integrate your application, website, or bot with our Netflix CDK system using clean REST endpoints.

GET /api/status

Check if active subscription slots are available in the system.

POST /api/check-cdk

Verify a CDK activation code and retrieve its plan type before redeeming.

Request Body
{ "key": "NETVXL-XXXX-XXXX" }
POST /api/redeem

Redeem a CDK key for Phone/Tablet, PC/Laptop, or background Smart TV activation.

Request Body (Phone / Tablet)
{ "key": "NETVXL-XXXX-XXXX", "deviceType": "phone" }
Request Body (PC / Laptop)
{ "key": "NETVXL-XXXX-XXXX", "deviceType": "pc" }
Request Body (Smart TV)
{ "key": "NETVXL-XXXX-XXXX", "tvCode": "12345678" }
GET /l/:code

Single-use masked redirection URL. Destroys itself upon single use to protect credentials.
